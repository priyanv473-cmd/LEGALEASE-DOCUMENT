# LEGALEASE-DOCUMENT# LegalEase – AI-Powered Legal Document Generator

LegalEase is an AI-powered web application that helps users generate professional legal document drafts using Generative AI.

## Features

- Generate legal document drafts using AI
- Support for different document types
- Enter details of both parties
- Add purpose and date
- Display generated document
- Download document as DOCX
- Download document as PDF
- Simple and user-friendly interface

## Technologies Used

- Python
- FastAPI
- Streamlit
- Google Gemini API
- python-docx
- FPDF2
- Pydantic
